# MDPINN-Dissimilar-Metal-WAAM
#This dataset contains the simulated data, the results obtained using the proposed multi-domain physics-informed neural network (MDPINN), and those obtained using a global PINN for the study entitled “Interface-Aware Multi-Domain Physics-Informed Neural Network for Thermal History Prediction in Dissimilar Metal Wire Arc Directed Energy Deposition.”
#The dataset includes temperature fields for dissimilar-metal wire arc-directed energy deposition (WADED) cases, which are used to validate the proposed MDPINN model. The simulation data were generated using the Transient Thermal module in ANSYS Workbench, incorporating thermal properties and heat source parameters obtained from the literature.Specifically, the dataset includes simulation results for ablation studies, parameter sensitivity analyses, and model generalizability assessments, along with the corresponding predictions from the proposed MDPINN and the global PINN.
